# Interactive Quizes

An interactive quiz application built with **HTML** and **JavaScript** to help users learn and test their knowledge of basic web development concepts.

## Features

- 🎯 Interactive quiz questions
- ⚡ Real-time feedback on answers
- 💾 Progress tracking
- 📱 Responsive design
- 🎨 User-friendly interface

## Technologies Used

- **HTML** - Structure and markup
- **JavaScript** - Interactivity and quiz logic
- **CSS** - Styling and layout

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/rajaramk8/interactiveQuizes.git
   ```

2. Navigate to the project directory:
   ```bash
   cd interactiveQuizes
   ```

3. Open `index.html` in your web browser to start taking quizzes.

## How to Use

- Select a quiz topic
- Answer the questions presented
- Submit your answers to see your score
- Review feedback for each question
